# FMECA Analysis Tool

Настольное приложение для анализа видов отказов, последствий и критичности (**FMEA / FMECA**, АВПКО) в области вычислительной техники и ЦОД.

---

## Русский

### Кратко о программе

Графическое приложение на **Python** и **SQLite**: ведение записей об отказах, расчёт **RPN**, отчёты **Excel/PDF**, графики и справочники. Ниже — как **установить**, **запустить** и **собрать .exe**; описание функций — в конце раздела.

---

## 1. Запуск готового .exe (без Python)

Подходит, если вам передали уже собранную программу или вы сами выполнили сборку (см. раздел 2).

### Где лежит файл

После сборки исполняемый файл находится здесь:

```
fmeca_app\
└── dist\
    └── FMECA_Analysis\          ← эту папку копируют на другой ПК
        ├── FMECA_Analysis.exe   ← запуск двойным щелчком
        ├── _internal\           ← библиотеки (не удалять)
        └── … (другие файлы PyInstaller)
```

**Полный путь в вашем проекте:**

`d:\1FMECA\fmeca_app\dist\FMECA_Analysis\FMECA_Analysis.exe`

(каталог `dist` появляется только после команды сборки `build_exe.bat`).

### Как запустить

1. Откройте папку `dist\FMECA_Analysis`.
2. Запустите **`FMECA_Analysis.exe`**.
3. При первом запуске рядом с `.exe` создаётся папка **`data`** с файлом базы **`fmea.db`**.
4. Если база пустая, автоматически загружаются **50 демонстрационных записей**.

### Что копировать на другой компьютер

| Копировать | Не копировать отдельно |
|------------|-------------------------|
| **Всю папку** `FMECA_Analysis` | Только один файл `.exe` без остальных файлов из папки |

На новом ПК Python **не нужен**.

### Данные пользователя

| Что | Где |
|-----|-----|
| База SQLite | `data\fmea.db` (рядом с `.exe`) |
| Экспорт Excel/PDF | туда, куда вы сохраните в диалоге «Сохранить как» |

## 2. Как создать .exe (сборка на Windows)

Нужны: **Windows**, установленный **Python 3.10+**, интернет для установки пакетов.

### Шаг 1. Открыть каталог проекта

```bat
cd d:\1FMECA\fmeca_app
```

(укажите свой путь к репозиторию).

### Шаг 2. Запустить сборку

**Вариант А — командный файл (проще всего):**

```bat
build_exe.bat
```

**Вариант Б — PowerShell:**

```powershell
.\build_exe.ps1
```

Скрипт сам установит зависимости из `requirements.txt` и `requirements-build.txt`, затем вызовет **PyInstaller**.

### Шаг 3. Дождаться окончания

В конце в консоли должно быть сообщение вроде: `Build complete!` и путь `dist`.

Обычно сборка занимает **1–3 минуты** (зависит от ПК).

### Шаг 4. Проверить результат

Убедитесь, что существует файл:

```
dist\FMECA_Analysis\FMECA_Analysis.exe
```

Запустите его двойным щелчком — должно открыться главное окно программы.

### Схема каталогов после сборки

```
fmeca_app\
├── build\                 ← временные файлы сборки (можно не трогать)
├── dist\
│   └── FMECA_Analysis\    ← готовое приложение для распространения
│       ├── FMECA_Analysis.exe
│       └── _internal\
├── build_exe.bat          ← запуск сборки
├── fmeca_app.spec         ← настройки PyInstaller
└── … исходный код (.py)
```

### PDF с кириллицей (по желанию)

Перед сборкой положите в папку **`fonts`** проекта файлы:

- `DejaVuSans.ttf`
- `DejaVuSans-Bold.ttf`

Без них PDF-отчёты могут отображать кириллицу некорректно.

### Если сборка не удалась

1. Проверьте: `python --version` (нужен 3.10+).
2. Вручную: `pip install -r requirements.txt -r requirements-build.txt`
3. Затем: `pyinstaller fmeca_app.spec --noconfirm --clean`
4. Текст ошибки смотрите в `build\fmeca_app\warn-fmeca_app.txt`.

- **Повторно:** меню **Справочники → Загрузить демо (50 записей)**.

## 5. RPN до и после мер

| Показатель | Откуда берутся оценки | Формула |
|------------|------------------------|---------|
| **RPN до мер** | Основные S, O, D (верх формы) | S × O × D |
| **RPN после мер** | Остаточные S, O, D (низ формы) | S_ост × O_ост × D_ост |
| **Снижение риска** | Разница | RPN до − RPN после |

Если в базе сохранён явный «остаточный RPN», используется он; иначе значение считается из остаточных S/O/D.

## 6. Основные возможности

**Записи FMEA / FMECA**
- Иерархия: система → подсистема → компонент → вид отказа.
- Оценки **S, O, D** (1–10) и **RPN = S × O × D**.
- Расширенные поля: функция, эффекты, меры, ответственный, срок, статус.
- Параметры **λ, α, β, t** и **критичность Cm = λ × α × β × t**.
- Остаточный риск, признаки ОПФ / скрытый отказ / ОППО, фаза миссии, режим работы.

**Анализ**
- Категории риска: низкий (&lt;40), средний (40–99), высокий (100–199), критический (≥200).
- Фильтр таблицы, режим «только актуальные» записи.

**Визуализация**
- RPN, матрицы S×O и критичности, рейтинг по Cm, граф зависимостей.

**Экспорт**
- Excel (несколько листов), PDF, полный PDF с графиками.

### Листы Excel при экспорте

| Лист | Содержание |
|------|------------|
| FMEA Analysis | Основная таблица (S, O, D, RPN) |
| FMECA полный | Все поля записи |
| Количественная критичность | λ, α, β, t, Cm |
| Сводка анализа | Статистика |
| До-После мер | RPN до / после / снижение |
| Топ-20 по RPN / Cm | Приоритетные записи |
