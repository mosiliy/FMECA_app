# FMECA Analysis Tool

Настольное приложение для анализа видов отказов, последствий и критичности (**FMEA / FMECA**, АВПКО) в области вычислительной техники и ЦОД.

Документ описывает установку, запуск, сборку исполняемого файла и функциональность. Разделы об установке и эксплуатации расположены перед описанием возможностей приложения.

---

## Русский

### Назначение

Приложение реализовано на **Python 3.10+** и **SQLite**, с графическим интерфейсом **Tkinter**. Поддерживаются ведение записей об отказах, расчёт **RPN**, количественная критичность **Cm**, справочники, импорт/экспорт (**Excel**, **PDF**), отчёты и визуализация.

---

## 1. Запуск собранного приложения (.exe)

Режим предназначен для эксплуатации **без установки Python**. Используется готовая сборка из каталога `dist` (см. раздел 2) или переданный архив с папкой `FMECA_Analysis`.

### Расположение исполняемого файла

Каталог `dist` создаётся только после успешной сборки PyInstaller. Структура результата:

```
fmeca_app/
└── dist/
    └── FMECA_Analysis/          — каталог для распространения
        ├── FMECA_Analysis.exe   — точка входа
        ├── _internal/           — зависимости PyInstaller (обязательны)
        └── …
```

Относительный путь к исполняемому файлу от корня репозитория:

`dist/FMECA_Analysis/FMECA_Analysis.exe`

### Порядок запуска

1. Переход в каталог `dist/FMECA_Analysis`.
2. Запуск `FMECA_Analysis.exe`.
3. При первом запуске рядом с исполняемым файлом создаётся каталог `data/` с базой `fmea.db`.
4. При пустой базе автоматически загружаются 50 демонстрационных записей (см. `demo_data.py`).

### Распространение на другие машины

| Рекомендуется | Не рекомендуется |
|---------------|------------------|
| Копирование **всего** каталога `FMECA_Analysis` | Копирование только `FMECA_Analysis.exe` без сопутствующих файлов |

На целевой машине интерпретатор Python не требуется.

### Хранение данных

| Тип данных | Расположение |
|----------|--------------|
| База SQLite | `data/fmea.db` (каталог рядом с `.exe`) |
| Файлы экспорта Excel/PDF | Путь, выбранный в системном диалоге сохранения |

## 2. Сборка исполняемого файла (Windows)

### Условия

- ОС Windows;
- Python 3.10 или новее;
- доступ к сети для установки пакетов через `pip`.

### Процедура сборки

**Шаг 1.** Переход в корень репозитория:

```bat
cd <путь_к_репозиторию>/fmeca_app
```

**Шаг 2.** Запуск одного из скриптов:

```bat
build_exe.bat
```

или

```powershell
.\build_exe.ps1
```

Скрипт устанавливает зависимости из `requirements.txt` и `requirements-build.txt`, затем выполняет `pyinstaller fmeca_app.spec`.

**Шаг 3.** Ожидание завершения сборки (обычно 1–3 минуты). При успехе в консоли отображается `Build complete!` и путь `dist`.

**Шаг 4.** Проверка наличия файла `dist/FMECA_Analysis/FMECA_Analysis.exe` и тестовый запуск.

### Каталоги, связанные со сборкой

```
fmeca_app/
├── build/              — артефакты PyInstaller (временные)
├── dist/
│   └── FMECA_Analysis/ — готовая сборка для распространения
├── build_exe.bat
├── build_exe.ps1
├── fmeca_app.spec      — конфигурация PyInstaller
└── …
```

### Шрифты для PDF с кириллицей

Перед сборкой в каталог `fonts/` репозитория помещаются (при наличии):

- `DejaVuSans.ttf`
- `DejaVuSans-Bold.ttf`

При отсутствии этих файлов кириллица в PDF-отчётах может отображаться некорректно.

### Устранение сбоев сборки

1. Проверка версии Python: `python --version` (требуется ≥ 3.10).
2. Ручная установка зависимостей:  
   `pip install -r requirements.txt -r requirements-build.txt`
3. Прямой вызов PyInstaller:  
   `pyinstaller fmeca_app.spec --noconfirm --clean`
4. Диагностика: `build/fmeca_app/warn-fmeca_app.txt`

## 5. Расчёт RPN до и после мер

| Показатель | Источник оценок | Формула |
|------------|-----------------|---------|
| RPN до мер | Основные S, O, D (верхняя часть формы) | S × O × D |
| RPN после мер | Остаточные S, O, D (блок остаточного риска) | S_ост × O_ост × D_ост |
| Снижение риска | Разность показателей выше | RPN до − RPN после |

Логика реализована в `FMEAModel.calculate_residual_risk()`. Если в базе задан явный `residual_rpn`, он имеет приоритет; иначе значение вычисляется по остаточным S/O/D.

## 6. Функциональность

### Записи FMEA / FMECA

- Иерархия: система → подсистема → компонент → вид отказа.
- Шкалы **S**, **O**, **D** (1–10), **RPN = S × O × D**.
- Расширенные поля: функция, локальный / верхний / конечный эффекты, меры контроля, рекомендации, ответственный, срок, статус.
- Параметры надёжности **λ**, **α**, **β**, **t**; **Cm = λ × α × β × t**.
- Остаточный риск; признаки ОПФ, скрытого отказа, ОППО; фаза миссии, режим работы.

### Анализ и фильтрация

- Категории риска по RPN: низкий (&lt;40), средний (40–99), высокий (100–199), критический (≥200).
- Поиск по таблице, фильтр «только актуальные» записи, очистка записей вне актуальной структуры FMECA.

### Визуализация

- Распределение RPN, RPN по компонентам и категориям, категории риска.
- Матрица S×O, матрица критичности, рейтинг по Cm.
- Граф зависимостей (компонент → отказ → причина → последствие).

### Экспорт и отчёты

- Excel — несколько листов (`io_utils.py`).
- PDF — краткий отчёт.
- Полный PDF — все записи по разделам и набор графиков (`reports.py`).

### Листы Excel

| Имя листа | Содержание |
|----------|------------|
| FMEA Analysis | Основная таблица (S, O, D, RPN) |
| FMECA полный | Полный набор полей записи |
| Количественная критичность | λ, α, β, t, Cm |
| Сводка анализа | Агрегированная статистика |
| До-После мер | RPN до / после / снижение |
| FMECA Standardized | Сводный формат (англоязычные заголовки) |
| Топ-20 по RPN / Cm | Приоритизация записей |
| Статистика RPN, Справка | Сводки и пороги RPN |

## English

### Overview

Desktop **FMEA / FMECA** application for IT and data-center scenarios. Stack: **Python**, **Tkinter**, **SQLite**.

### Run the built executable

Path after build: `dist/FMECA_Analysis/FMECA_Analysis.exe`

Distribute the entire `dist/FMECA_Analysis` folder. Python is not required on the target machine. Database: `data/fmea.db` next to the executable.

### Build on Windows

```bat
cd fmeca_app
build_exe.bat
```

Output: `dist/FMECA_Analysis/FMECA_Analysis.exe`

### Run from source

```bash
pip install -r requirements.txt
python main.py
```

Default database: `data/fmea.db` in the repository root.

### Features (summary)

FMEA/FMECA records, RPN and Cm, editable dictionaries, Excel/PDF export, charts, dependency graph, 50 demo records on first run with an empty database.

### RPN before / after actions

- Before: main S, O, D → RPN = S × O × D  
- After: residual S, O, D → residual RPN  
- Risk reduction: difference between the two
